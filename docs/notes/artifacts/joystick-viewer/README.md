# joystick-viewer —— 摇杆平面与支点查看器

把驱动里 `pico_neo3_leftcontroller/` 的 `.orig` 网格按**实测的按键平面**摆好，并按 vrserver 的摇杆公式
（`A = [S|c]·T(press)·Rz(θx)·Rx(θy)·[S|c]⁻¹`）驱动摇杆，用来看支点、转轴和摆幅对不对。
结论引用见 [`../../04_g-driver-hand-grip.md`](../../04_g-driver-hand-grip.md)。

## 运行

```sh
uv run python get_three.py                    # 拉 three.js r169（校验 SHA-256，约 1.3 MB，只需一次）
uv run --with numpy python export_model.py    # 生成 web/model.js（默认读 Program Files 下的驱动，可用 --driver 指定）
uv run python serve.py                        # 浏览器打开 http://127.0.0.1:8788/
```

`web/model.js`、`web/three.module.js`、`web/shots/` 是本地产物，不进仓库。

## 哪些是实测、哪些是人选的

| 项                             | 来源                                                                                                                                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 按键平面法向、平面位置         | 4 颗按键帽的 PCA 薄轴，互差 ≤2.4°；符号由「闭口圆盘是帽顶」判定                                                                                                                                  |
| 摇杆轴位置                     | 方向固定为法向，只拟合 2 个平移自由度（±2 mm 网格搜索）                                                                                                                                          |
| 帽顶露出 7.44 mm、埋入 3.01 mm | 沿法向的高度剖面                                                                                                                                                                                 |
| `rotate_xyz`、两条转轴         | 由法向与平面内的「上」解出（「上」= 世界 up 的投影，一条转轴严格水平）；写进驱动前要按握把补丁之后的法向 `R·n` 再算一遍（见 [`../../04_g-driver-hand-grip.md`](../../04_g-driver-hand-grip.md)） |
| 按下 2.5 mm、压进去            | 厂商行程；**符号取反**（厂商原值在实机上是往外弹，见 `04_g`）                                                                                                                                    |
| **满偏倾角 12°**               | **用户在页面上按手感选定**（厂商是 6.5°；写进驱动时 Y 轴取反号，实机定）                                                                                                                         |
| **支点沿轴偏移 +4.0 mm**       | **用户在页面上按手感选定**（几何参考：杆底在平面下 3.01 mm，支点再低 0.99 mm）                                                                                                                   |
| 平面内的「上」                 | **用户最终选择**：取**世界 up 的投影**（几何参考，一条转轴严格水平）；手感补偿那轮试过 1.03–6.00° 与反向 −3.00°，读数不收敛，已全部撤掉                                                          |

最后两行不是测出来的量，是人的选择。要改就改页面上的滑杆，再把值写进 `patch_driver.ps1`。

页面显示的是握把补丁**之前**的模型空间：支点要再走一次 `R·p − t`；`rotate_xyz` 要按补丁后的法向 `R·n` 重算（左 `[0, -156.718, 163.333]`、右 `[0, -156.753, -163.329]`）。推导与复核见 [`../../04_g-driver-hand-grip.md`](../../04_g-driver-hand-grip.md)。

## 操作

- 左键拖动旋转（转盘式：世界竖直锁定、俯仰限位，不会转歪）、右键或 Shift 平移、滚轮远近、双击复位（视角与旋转中心都回到预设）、`WASD` 平移（在屏幕平面内，跟右键平移同一手势；旋转中心会跟着平移走，双击即回摇杆）、`Q`/`E` 推拉
- 「画面旋转」：把相机锁定的竖直轴转开（`0°` 就是原来的转盘手感），画面跟着滚转；`Q` / `E` 可微调（原来 `Q` / `E` 的推拉已让位，推拉用滚轮），切视角会归零
- 「镜像（右手）」：整组（模型、平面、两条轴、支点、杆轴）按 x 镜像，看右手用；右手 JSON 的摇杆参数就是左手镜像，所以镜像后的表现即右手。视角预设、剖切平面、跟踪环切口也一起按镜像摆好，切换镜像会按当前预设重新摆相机
- 「模拟推动」：推右 / 推左 / 推上 / 推下 / 回中，或「绕圈自动推」
- 「支点沿轴偏移」可负：`+` 是平面下方（机身内），`−` 是平面上方
- 「切掉跟踪环」：跟踪环挡在平面正前方，正对法向看必被它遮住，需要切开才看得到摇杆
- 「对照：厂商参数」画出厂商那套支点与 `rotate_xyz = 0` 的线框，便于对比
- 读数：帽顶相对位移（右 / 上 / 法向）、摇杆在平面处的半径变化（判断裙边是否顶到孔沿）
